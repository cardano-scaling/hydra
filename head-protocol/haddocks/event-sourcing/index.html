event-sourcing

An EventSource/EventSink abstraction for an ordered, identified event stream, a checkpoint-by-aggregate log rotation combinator, and a production SQLite backend (WAL, user_version schema migrations, async write-behind through a bounded queue, and VACUUM INTO archival on rotation). Polymorphic in the base monad via io-classes where practical.
