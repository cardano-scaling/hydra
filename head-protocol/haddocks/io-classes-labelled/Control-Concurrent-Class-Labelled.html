Description

Thin wrappers over io-classes that attach a label to the STM primitive or thread they create.

The labels surface in io-sim traces and as GHC thread labels, which makes deadlock and liveness diagnosis tractable. Applying them everywhere a TVar/TMVar/TQueue/TBQueue is allocated or a thread is spawned is a discipline worth keeping; these helpers make it the path of least resistance.
