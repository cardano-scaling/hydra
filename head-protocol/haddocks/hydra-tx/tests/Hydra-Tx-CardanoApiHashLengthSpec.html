spec :: Spec Source #

Regression tests for GHSA-cgpq-8874-8pq8: a wrong-length credential, TxId or datum hash (attacker-controlled via an on-chain Commit datum) crashed these conversions with an uncaught error instead of failing gracefully, taking down chain observation. Plutus hashes are bare BuiltinByteStrings with no type-level length guarantee, so every one of them has to be validated at this boundary.
