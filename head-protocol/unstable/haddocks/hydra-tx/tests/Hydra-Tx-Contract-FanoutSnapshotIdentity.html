Hydra.Tx.Contract.FanoutSnapshotIdentity

Description

Regressions for equal-value output substitution during fanout.

Every attack pays an output which has exactly the value of a live output but a different identity. Consequently value conservation and token burning are valid; only the accumulator membership check can reject it.
