withFreeServerSocket :: (Socket -> PortNumber -> IO a) -> IO a Source #

Allocate a listening socket on a free port and hand both it and its port to the action. The server is then given the very socket it serves on, so the port cannot be taken in the gap between choosing it and binding it. That gap used to surface as a flaky RunServerException carrying "Address already in use".
