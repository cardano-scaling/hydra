closedToPartialFanout :: ClosedState tx -> UTxOType tx -> UTxOType tx -> FanoutMode tx -> OnChainFanoutDatum -> PartialFanoutState tx Source #

fanoutProgressToClosed :: PartialFanoutState tx -> ClosedState tx Source #

Rebuild the ClosedState from a PartialFanoutState when clearing a local fanout request (see HeadFanoutReverted). The Head stays Closed. The head owner only applies this to pending fanout, before any distribution. The candidate and notification state remain available before the deadline, including after a checkpoint or a failed early request.
