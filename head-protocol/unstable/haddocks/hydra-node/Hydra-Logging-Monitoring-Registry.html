sampledCounter :: Registry -> Text -> Text -> IO Gauge Source #

Absolute, possibly fractional counters (e.g. RTS CPU seconds). The client's incrementable Counter stores Int; sample these through a Gauge handle and publish their counter type. Callers supply monotonically increasing values.
