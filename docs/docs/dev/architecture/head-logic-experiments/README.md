# Head logic experiments

The chosen design is documented in [the review guide](../../../../head-logic-review.md)
and [Programs inside crem](../../../../head-logic-crem-workflows.md). This directory
collects the experiments and their evidence. Earlier measurements describe the
code version named in each section; they are not all measurements of today's node.

| Experiment or record | What to look for |
| --- | --- |
| [Lab guide](lab.md) | Commands for traces, explorer, primitive replay, resolved changes, and the maintenance exercise. |
| [Peer demonstration](demonstration.md) | A real Cardano witness-replacement bug, retry expiry, and settlement/rollback schedules. |
| [Bug ledger](bugs.md) | Reproducers, fixed defects, retained behavior, and findings queued for a separate fix. |
| [Snapshot capacity](capacity.md) | Investigation of upstream PR #2927: request evidence, selection/pruning, and the missing progress check. No rebase or capacity fix is applied here. |
| [Measurements](measurements.md) | Local rounds, allocations, recovery, whole-node throughput, and the limits of each comparison. Raw summaries are in `measurements/`. |
| [Original sketch](original-sketch.md) | The earlier proposal. The current rule/module design is in the review guide. |
| [Agda generation proposal](agda-generated.md) | How machine-checked rules might generate the Haskell layer; speculative, with no production code change. |
| [Free-program/workflow comparisons](workflows/README.md) | Five migrated handlers compared with frozen free programs or handlers. |
| [Saved scenarios](traces/README.md) | Versioned counterexamples, normal-interpreter runs, and recorded demonstrations. |
| Full input comparisons (`inputs/`) | Init through fanout, including synchronization and settlement. Generated by `head-logic-lab trace-inputs`. |

[All diagrams](../../../../head-logic-diagrams.md) renders every `.mmd` file with
its purpose. It includes historical artifacts as well as current topologies and
traces. Regenerate it after changing a diagram:

```sh
python3 scripts/head-logic-diagrams.py
python3 scripts/head-logic-diagrams.py --check
```

The general explorer remains a bounded snapshot-message scheduler. The complete
input entry point is shared, but deposit/settlement/rollback coverage comes from
focused schedules, not an exhaustive explorer over chain events. Independent
settlement backends remain outside this spike.
